# 📄 Finiquito

> Spanish severance & final-settlement calculator: unfair dismissal (33 days/year, pre-2012 45 days), objective dismissal (20), end of temporary contract (12), unused holidays and pro-rated bonus.

**Free · open source · 100% in your browser (nothing is uploaded).**

<sub>[🇪🇸 Español abajo](#-español)</sub>

## Features
- Reform-2012 dual brackets and caps (720/1260 days)
- finiquito breakdown

## Use
Open `index.html` — no install, no server, no build. Host it free on GitHub Pages.

## Basis
Estatuto de los Trabajadores arts. 49, 53, 56; RDL 3/2012.

## ⚠️ Disclaimer
Orientative tool — not legal, tax or financial advice. Check your specific case with a professional.
